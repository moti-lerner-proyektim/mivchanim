# מחוללי בחינות ומאגר שאלות בגרות

אתר מבחנים שרץ ב-GitHub Pages (`moti-lerner-proyektim.github.io/mivchanim/`) ושומר ציונים בגיליון Google.

ארבעה נושאים בדף הראשי, כולם על אותו מנוע ואותו גיליון:

| נושא | קישור לתלמידים |
| --- | --- |
| מחולל בחינות – כיתה ט׳ | `exam.html?grade=9` |
| מחולל בחינות – כיתה י׳ | `exam.html?grade=10` |
| מחולל בחינות – כיתה יא׳ | `exam.html?grade=11` |
| מאגר שאלות לבגרות בתקשוב | `exam.html?grade=bagrut` |

כל מבחן משויך לשכבה אחת. תלמיד שנכנס דרך הכרטיס של השכבה רואה רק את המבחנים הפתוחים שלה.

- **ארבעה סוגי שאלות**: רב ברירה, השלמה (עד 5 חלונות בשורה), נכון/לא נכון, והעברת חיצים.
- **עד 40 שאלות** בכל מבחן, ולכל שאלה אפשר לצרף **תמונה**.
- **תלמיד** נכנס עם שם, כיתה ותעודת זהות (נבדקת ספרת ביקורת).
- כל תלמיד מקבל **סדר שאלות אחר וסדר תשובות אחר** בכל שאלה.
- הבדיקה נעשית **בשרת** (בגיליון), כך שהתשובות הנכונות לא מגיעות לדפדפן של התלמיד.
- התלמיד רואה רק את הציון הסופי.
- **מורה** מנהל מבחנים, שאלות ותוצאות מתוך `teacher.html`, עם סיסמה.

## מבנה הקבצים

| קובץ | תפקיד |
| --- | --- |
| `index.html` | דף הבית: ארבעת הנושאים |
| `exam.html` | דף התלמיד (המבחן עצמו) |
| `teacher.html` | ממשק המורה (קישור "כניסת מורה" בדף הבית) |
| `js/config.js` | **כאן מדביקים את כתובת השרת** |

## מצב הדגמה

כל עוד `API_URL` ב-`js/config.js` ריק, האתר עובד בלי גיליון: הנתונים נשמרים רק בדפדפן שלכם. כך אפשר לנסות הכול מיד. סיסמת המורה בהדגמה: `1234`.

## התקנה (פעם אחת, כ-15 דקות)

### שלב 1: הגיליון והשרת

1. צרו גיליון Google חדש, למשל "מחוללי בחינות – תוצאות".
2. בתפריט: **הרחבות ← Apps Script**.
3. מחקו את מה שכתוב שם, והדביקו את כל התוכן של `apps-script/Code.gs`. שמרו (Ctrl+S).
4. בסרגל העליון בחרו את הפונקציה **setup** ולחצו **הפעלה (Run)**.
   - בפעם הראשונה Google יבקש הרשאות: "בדיקת הרשאות" ← בחרו את החשבון ← "מתקדם" ← "מעבר אל הפרויקט" ← "אישור".
   - בגיליון ייווצרו שלוש לשוניות: `Exams`, `Questions`, `Results`, ומבחן לדוגמה.
5. לחצו **פריסה (Deploy) ← פריסה חדשה (New deployment)**.
   - סוג: **אפליקציית אינטרנט (Web app)**.
   - הפעלה בתור: **אני (Me)**.
   - למי יש גישה: **כל אחד (Anyone)**.
   - לחצו "פריסה" והעתיקו את **כתובת ה-Web app** (מסתיימת ב-`/exec`).

### שלב 2: האתר ב-GitHub

1. בארגון `moti-lerner-proyektim` צרו מאגר חדש בשם **`mivchanim`** (Public), והעלו אליו את כל הקבצים מהתיקייה הזו.
2. פתחו את `js/config.js` (בעריכה ישירה ב-GitHub) והדביקו את הכתובת:
   ```js
   API_URL: 'https://script.google.com/macros/s/XXXX/exec',
   ```
3. **Settings ← Pages**: Source = `Deploy from a branch`, Branch = `main`, תיקייה `/ (root)`. שמרו.
4. אחרי דקה-שתיים האתר זמין בכתובת `https://moti-lerner-proyektim.github.io/mivchanim/`.

### שלב 2א: הכרטיס בדף השער "לומדים בעצמי"

במאגר של דף השער (`moti-lerner-proyektim.github.io`) החליפו את `index.html` בקובץ `index.html` המעודכן (נשלח בנפרד מה-zip).
השינוי היחיד: הכרטיס "בגרויות — ליבת תקשוב" (שהיה "בקרוב") נקרא עכשיו **"מחוללי בחינות ומאגר שאלות בגרות"** והוא קישור פעיל לאתר החדש. התמונה `images/bgruyot.jpeg` נשארת.

### שלב 3: אבטחה

1. היכנסו ל-`teacher.html` עם הסיסמה `1234`.
2. **מיד** עברו ללשונית "הגדרות" והחליפו סיסמה.

## עבודה שוטפת

1. **מבחנים ← + מבחן חדש**: שם, **שכבה** (ט׳ / י׳ / יא׳ / בגרות), זמן בדקות (0 = ללא הגבלה), כיתות מופרדות בפסיקים. בראש הרשימה אפשר לסנן לפי שכבה.
   - "מספר שאלות לתלמיד": אם תזינו 10 ובמאגר יש 25 שאלות, כל תלמיד יקבל 10 שאלות מוגרלות.
2. **שאלות ← + שאלה חדשה**, ובחלון בוחרים את סוג השאלה (עד 40 שאלות במבחן):

   | סוג | איך כותבים | ניקוד |
   | --- | --- | --- |
   | א. רב ברירה | 2–6 תשובות, מסמנים בעיגול את הנכונה | הכול או כלום |
   | ב. השלמה | כותבים `___` בכל מקום חסר (או לוחצים "+ חלון השלמה"). עד 5 חלונות בשורה, אפשר כמה שורות. לכל חלון כותבים תשובה נכונה, וכמה חלופות מפרידים ב- `/` | חלקי: כל חלון נכון מקבל חלק יחסי |
   | ג. נכון / לא נכון | כותבים משפט ומסמנים אם הוא נכון | הכול או כלום |
   | ד. העברת חיצים | 2–8 זוגות (פריט מימין ← ההתאמה שלו משמאל). אצל התלמיד שני הטורים מעורבבים, והוא מחבר בקו | חלקי: כל חיבור נכון מקבל חלק יחסי |

   - בדיקת השלמה מתעלמת מרווחים, אותיות גדולות/קטנות, ניקוד, אותיות סופיות ופיסוק בקצוות. מספרים נבדקים כערך (3 = 3.0).
   - **תמונה**: "בחירת קובץ" מעלה את התמונה לתיקייה "מחולל בחינות – תמונות" ב-Google Drive שלכם ומשתפת אותה לצפייה בקישור. אפשר גם להדביק קישור לתמונה (https). אם בית הספר חוסם שיתוף קבצים מ-Drive, התמונה מכווצת ונשמרת ישירות בגיליון, באיכות נמוכה יותר.
   - תלמיד יכול ללחוץ על תמונה כדי להגדיל אותה.
3. **פתיחה**: לחצו "פתיחה" ליד המבחן. התלמידים ימצאו אותו בכרטיס של השכבה בדף הבית, או שתשלחו קישור ישיר בעזרת "העתקת קישור".
4. **תוצאות**: ממוצע, ציון גבוה ונמוך, סינון לפי כיתה וייצוא לאקסל. כל ההגשות נשמרות גם בלשונית `Results` בגיליון, כולל התשובות של כל תלמיד.

## דברים שחשוב לדעת

- **עדכון קוד השרת בעתיד**: מדביקים את `Code.gs` החדש, מריצים שוב `setup` (בטוח, לא מוחק נתונים), ואז **פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה**. בלי זה הכתובת ממשיכה להריץ את הגרסה הקודמת.
- **הגשה חוזרת**: כברירת מחדל תלמיד לא יכול להגיש פעמיים את אותו מבחן עם אותה תעודת זהות. אפשר לשנות בהגדרות המבחן.
- **זמן**: כשהזמן נגמר, המבחן מוגש אוטומטית. הגשה שמגיעה יותר מ-2 דקות אחרי הזמן מסומנת "באיחור".
- **ריענון דף**: התשובות נשמרות בדפדפן, כך שריענון לא מוחק אותן.
- **פרטיות**: הגיליון מכיל שמות ותעודות זהות של תלמידים. אל תשתפו אותו. השרת לא מחזיר לתלמיד נתונים של תלמידים אחרים.
- **עומס**: Google מאפשר כ-30 בקשות בו-זמנית. כיתה של 35 תלמידים שמגישים יחד תעבוד, אבל ייתכן עיכוב של כמה שניות.
- **מגבלה**: מבחן שרץ בדפדפן אינו מונע העתקה או חיפוש ברשת. מומלץ להעביר אותו בכיתה ובהשגחה.
